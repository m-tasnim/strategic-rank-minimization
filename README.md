# Strategic Rank Minimization

Code accompanying the paper:

> Tasnim, M., Weesie, Y., Ghebreab, S.
> *Strategic manipulation of preferences in the rank minimization mechanism.*
> Autonomous Agents and Multi-Agent Systems **38**, 44 (2024).
> [https://doi.org/10.1007/s10458-024-09668-3](https://doi.org/10.1007/s10458-024-09668-3)

This repository contains the implementation of the rank minimization (RM) matching mechanism via the Hungarian algorithm (RM-HAL), along with the first-order heuristic strategy and the experiments reported in the paper.

## Overview

The code supports four experiments:

1. Matching performance of RM-HAL with truthful and strategic preferences across varying values of top-*n*.
2. Matching performance with varying fractions of strategic agents.
3. Combined sweep over top-*n* and fraction of strategic agents.
4. Comparison of outcomes between truthful and strategic agent groups.

Experiments are run on both synthetic markets (logistic, linear, exponential demand) and real preference data from secondary school choice in Amsterdam (VWO, HAVO, VMBO tracks).

## Data

Synthetic preference profiles are generated by the code.

The Amsterdam preference data (this paper uses data from 2017 loting en matching) is not included in this repository due to privacy restrictions. 
It can be obtained from the Association of School Boards in Amsterdam Secondary Education (OSVO) upon request.
